# hxyfront-62010 潜水气瓶充填记录

源提示词编号：5

我想做一个给潜水店使用的气瓶充填前端系统，工作人员可以记录气瓶编号、容积、检验有效期、残压、目标压力、氧含量、氦含量、充填方式和操作员。页面需要有待充填队列、混合气比例提示、气瓶检验过期提醒、充填完成签收和单个气瓶历史记录。

## 充填泄漏应急闭锁

- 触发：充填中压力连续 3 个采样点持续下降（自动），或点击顶部「手动急停」
- 立即冻结当前气源批次；进行中气瓶转「待检」，只保留已记录压力，禁止改写
- 未开工单停止排班，闭锁期间所有工单不得签收
- 主管完成泄漏检查并复位（合格解冻）后，工单必须逐瓶重验：合格回队列恢复，不合格转隔离
- 同一事故（同气源复发）重复复位沿用首次泄漏检查结果，逐瓶重验沿用各瓶首次结论，不得改判
- 气源、工单、事故与单瓶历史均持久化到 localStorage，刷新页面后一致
